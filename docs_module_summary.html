Initial D THE ARCADE Data Viewer
モジュール分割構成および機能仕様書

作成日: 2026年10月13日 リポジトリ: Pand-GtHb/initialdac-round-data-auto-json-00
旧一枚岩構成（約16,000行・380KBの単一スクリプト）から、責務に応じた8つの独立モジュールへの段階的分割が完了しました。
各モジュール名には依存順・読み込み順を反映した4桁のプレフィックス（0100_〜0800_）を付与し、メンテナンス性と堅牢性を大幅に向上させています。

2. 依存関係と読み込みアーキテクチャ

[0100_utils.js] (基盤ユーティリティ) │ ▼ [0200_domain.js] ────┐ (ドメイン定義・統計計算) │ │ ▼ ▼ [0300_persistence] [0400_data] [0500_matching] [0600_ui] (独立専門機能群) (永続化層) (データ通信) (マッチング算出) (UI描画) │ │ │ │ └───────────────────┴──────┬───────┴──────────────┘ │ ▼ [0700_app.js] (状態管理・業務ユースケース統括) │ ▼ [0800_main.js] (起動ブートストラップ・DOMイベント接続)
設計と配置の特記事項:
  • 並び順の整合性: 4桁の数値プレフィックス（0100〜0800）により、ファイル一覧上で常に依存関係通りの順序で表示されます。
  • データファイルの保護: areaList.json や scoring_config.json などのデータファイルは改名せず維持しているため、GitHub Actions等の自動取得パイプラインを壊さず、ファイル名ソート順で自然に後方へまとまります。
  • 保守用の安全装置: tests/ フォルダ（全64件の回帰テスト）および tools/serve.js（ローカル検証サーバー）により、今後の安全な改修体制が確立されています。
